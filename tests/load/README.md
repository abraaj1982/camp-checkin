# اختبارات الضغط والاستقرار (tests/load)

أدوات تطوير فقط. **لا تُنشر، ولا تعمل على الإنتاج، ولا تكتب في أي شيت.**

## كيف تعمل
- `lib/` يشغّل **كود الخادم الحقيقي** (`server/*.gs`) داخل محاكٍ محلي لـ Apps Script:
  - كل طلب يعمل في خيط مستقل (فتحة تنفيذ).
  - قفل واحد حقيقي بمهلة انتظار.
  - ذاكرة مؤقتة مشتركة.
  - زمن لكل عملية على الشيت، معايَر على منصة Google الحقيقية.
- **البيانات وهمية بالكامل:** أسماء تنتهي بـ «التجريبي»، والهاتف 99990000، والشيتات في الذاكرة فقط.
- **اختبارات المتصفح** تفتح الصفحات الحقيقية (`supervisor.html`, `login.html`). أي طلب إلى `script.google.com` يُجاب من المحاكي المحلي، وأي طلب آخر خارج الجهاز يُمنع ويُعدّ (الاختبار Q14 يتأكد أنه صفر).

## التشغيل
```
node tests/server.test.js                   # الاختبارات الأساسية (كما هي)
node tests/load/concurrency.test.js         # التزامن، منع التكرار، الصلاحيات، أمان الجلسات، سباق الدخول (~2 د)
node tests/load/endurance.test.js           # الجلسات خلال يوم 5 ساعات بساعة مُحاكاة (ثوانٍ)
node tests/load/queue.test.js               # طابور المشرف في المتصفح: انقطاع، إغلاق، إعادة تشغيل، جهاز آخر… (~8 د)
node tests/load/sim.js expected             # سيناريو الحِمل: 300 طالب، 8 مشرفين، 25 مستخدماً (~5 د)
node tests/load/sim.js peak|spike|stress|breaking|quick
node tests/load/responses.js record f.json  # تسجيل ردود 400 عملية، ثم بعد التعديل:
node tests/load/responses.js compare f.json # يثبت أن الردود لم تتغير
```
النتائج تُحفظ في `tests/load/results/` (خارج git).

## الأمان
- `probe-real.js` هو الملف الوحيد الذي يتصل بمنصة حقيقية، ويرسل طلبات **قراءة فقط** (رمز غير صالح، ومستخدم غير موجود).
- `guard.js` يرفض تشغيله:
  - بدون `MK_I_CONFIRM_NOT_PRODUCTION=yes`.
  - على أي رابط نشر موجود في صفحات هذا المستودع (أي الإنتاج).
  - على أي رابط ليس `/exec` من Apps Script.

## حدود
- زمن الكتابة الحقيقي على Google Sheets لا يُقاس هنا، بل في نسخة LOAD منفصلة.
