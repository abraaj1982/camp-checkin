# Boom Oman

تطبيق توصيل طرود على غرار Boom AE، مخصص لسوق عُمان — يربط العملاء بالسائقين مباشرة مع مقارنة أسعار، اختيار السائق، وتتبع مباشر للطلب.

## MVP الحالي (تجربة العميل)

- **تسجيل دخول**: رقم هاتف عُماني (+968) مع رمز تحقق (OTP وهمي للتجربة).
- **طلب توصيل**: إدخال موقع الاستلام والتسليم وملاحظة عن الطرد.
- **عروض أسعار السائقين**: قائمة سائقين وهميين بأسعار وتقييمات ووقت وصول مختلف، مرتبة حسب السعر.
- **تتبع الطلب**: شريط تقدم (تعيين السائق → الاستلام → في الطريق → التسليم) يتحرك تلقائيًا للمحاكاة.

البيانات حاليًا محلية (Mock) بدون خادم فعلي، لتسهيل تجربة الواجهة أولًا قبل بناء الـ backend.

## التشغيل

```bash
cd boom-oman
npm install
npm run start   # ثم اضغط i لـ iOS أو a لـ Android أو w للويب
```

يتطلب [Expo Go](https://expo.dev/go) على جوالك لتجربته مباشرة بدون بناء تطبيق كامل.

## الخطوات التالية المقترحة

1. **تطبيق السائق**: شاشة "متاح الآن"، استقبال الطلبات، تحديد السعر، قبول/رفض.
2. **خادم فعلي**: مصادقة حقيقية (Firebase Auth / OTP عبر SMS)، قاعدة بيانات طلبات وسائقين، مطابقة حسب الموقع الجغرافي.
3. **خرائط وتتبع حي**: دمج خرائط (Google Maps / Mapbox) لعرض موقع السائق فعليًا.
4. **الدفع**: بوابة دفع محلية عُمانية + دفع نقدي.
5. **نظام الخصومات والتقييمات** كما في Boom الأصلي.

## هيكلة المشروع

```
boom-oman/
  app/              شاشات Expo Router (login, home, offers, tracking)
  src/state/         إدارة الحالة (تسجيل دخول، الطلب النشط)
  src/data/           بيانات وهمية للسائقين
  src/theme/          الألوان
  src/types.ts        الأنواع المشتركة
```
