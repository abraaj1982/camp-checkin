# CORE HR — المرحلة 1 (MVP، شركة واحدة)

Node 22 + Express + SQLite (`node:sqlite` المدمجة) + واجهة عربية RTL بلا أدوات بناء.

## التشغيل
```bash
cd core-hr && npm install
ADMIN_PASSWORD='كلمة-قوية' npm run seed   # ينشئ admin وأنواع الإجازات والإعدادات
npm start                                  # http://localhost:3000
npm test
```
متغيرات: `PORT`, `DB_FILE`, `JWT_SECRET` (وإلا يُولَّد في `data/.jwt_secret`).

## ما هو منجز
- الأدوار: مدير نظام / موارد بشرية / مدير / موظف، وكل نقطة API تتحقق من الصلاحية والنطاق (المدير يرى فريقه فقط).
- بيانات الموظفين، والأقسام، وإنهاء الخدمة.
- الحضور والانصراف مع النطاق الجغرافي (Haversine) وحساب التأخير بتوقيت عُمان.
- الإجازات: أرصدة، تجاهل الجمعة والسبت، منع التداخل، مسار موافقة مدير ← موارد بشرية، ومنع الموافقة على طلب النفس.
- لوحة تحكم وسجل تدقيق.

## ملاحظات يجب مراجعتها قبل الإنتاج
- أرصدة الإجازات (30/10/6) قيم افتراضية، وتُراجع مع المستشار القانوني.
- الـ GPS من المتصفح قابل للتزوير؛ لحماية أقوى يلزم تطبيق جوال وفحص Mock Location.
- لا يوجد HTTPS هنا: شغّله خلف Reverse Proxy (Nginx/Caddy) مع TLS.
- العطلات الرسمية تُضاف في جدول `settings` (مفتاح `holidays`، مصفوفة JSON لتواريخ ISO).
- مؤجَّل للمراحل التالية: العقود، العقوبات، الرواتب/WPS، المهام، كور شير، سيف AI.
