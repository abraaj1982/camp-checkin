# ربط شاشة العرض (قراءة فقط)

شاشة العرض مشروع منفصل يقرأ **المنشور للجمهور فقط** من المنصة. لا تحمل أي بيانات طلاب أو صحة أو جوالات.

## التفعيل (مرة واحدة)
1. في محرر Apps Script شغّل الدالة `ADMIN_createFeedKey`، وانسخ المفتاح من السجل (`FEED_KEY = ...`).
2. ضع المفتاح في مشروع شاشة العرض. **لا ترفعه إلى GitHub العام**، وضعه في إعداد خاص أو متغير.
3. لتغيير المفتاح (إن تسرّب) شغّل الدالة نفسها مرة أخرى، فيبطل القديم فوراً.

## الاستدعاء
```js
const res = await fetch(APPS_SCRIPT_URL, { method: 'POST', body: JSON.stringify({ action: 'feed', key: FEED_KEY }) });
const data = await res.json();
```

## الاستجابة
```json
{
  "success": true,
  "serverTime": "2026-12-28T15:00:00.000Z",
  "campStart": "2026-12-27",
  "announcements": [
    { "id": "A..", "title": "حفل الافتتاح", "body": "في الساحة", "kind": "event",
      "startsAt": "2026-12-28T18:00:00.000Z", "pinned": true, "publishedAt": "...", "audience": "public" }
  ],
  "results": [
    { "competition": "كرة القدم", "rows": [ { "team": "الأزرق", "place": 1, "points": 30 } ] }
  ]
}
```
- `kind: "event"` مع `startsAt`: يُعرض معه عدّ تنازلي. احسب الفرق من `serverTime` لا من ساعة الجهاز.
- المثبّتة (`pinned`) أولاً. النتائج تظهر **بعد نشرها** من حساب يملك صلاحية «التحقق من النتائج».
- اقتراح التحديث: كل 15–30 ثانية. عند فشل الاتصال أبقِ آخر محتوى معروضاً.
- أوقات الصلاة: غير مضمّنة (تحتاج المدينة). يمكن حسابها في شاشة العرض نفسها.
